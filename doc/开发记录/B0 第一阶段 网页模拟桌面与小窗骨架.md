# B0 第一阶段：网页模拟桌面与小窗骨架

日期：2026-11-16　|　依据：策划提交 a11a3ad、dde27ea（`doc/策划案/透明界面与跨专题同步 v0.2/` 00—09）；范围按 06 §4 第一阶段。

## 1. 开发方式

沿用适者生存：`src/Core` 纯 C# 内核（不依赖 UnityEngine，兼作 Unity 本地包 `com.moyu.core`）+ Blazor WebAssembly 网页壳 + NUnit；推到 main 由 GitHub Actions 测试后发布到 Pages。以后 PC 端用 Unity 接同一内核。

网页版没有真桌面，整页做成**模拟桌面**：1920×1080 逻辑像素按视口等比缩放；壁纸、桌面图标（可单击选中、双击打开）、记事本窗口、任务栏都是"下层应用"，用来验证透明区穿透。

## 3. 开发假设（待 B0 答复）

- Q1 收起：缩成小熊头像留在小窗左下（角色处），可拖，单击恢复；任务栏的桌面摸鱼按钮也能收起/恢复/重新打开。
- Q2 网页版：设置里不显示"置顶""后台输入"；假记事本已放上，但第一阶段不计任何输入。
- Q3 美术：没有切效果图，改为开发方按 G 粗笔风格用 SVG 画占位场景与小熊（三种姿态：路亚拉竿、摸鱼下水、手竿竿架打盹），分层天然分开，等正式素材替换。三张地图共用一套区域（岸 x 40—1560、y 540—590；浅水 x 40—1560、y 650—760；画布 1600×900），只换配色和装饰：荷塘青绿、溪流青蓝加石头、海湾浅蓝加码头。
- Q5 文字：照效果图上的字；地图叫"地图一/二/三"；放不下提示"这里放不下"；房间按钮"邀请好友"、悬停提示"取消静音/收起/关闭/恢复"等为开发方占位；桌面右下注明"界面文字与美术均为占位"。
- 静音默认开（01 §6"默认建议静音"），目前没有任何声音。
- 关闭：网页里小窗消失，双击桌面图标或点任务栏按钮再打开（PC 端是退出程序）。
- 从"更多"打开的地图/皮肤/设置面板开着时，"更多"保持高亮，再点"更多"关掉面板。

## 4. 偏差与未做

- 面板里的鱼（小银鱼 23.6 cm、巨尾鱼 42.0 cm）是效果图示例，只在网页壳里，不进内核和配置（03 §6、ECON-04）；出售、放入收藏、设为背景、抽取等按钮全部禁用（UI-10）。
- 开发入口 `?dev=1`：模拟一条鱼获（先进鱼篓再出提示，UI-07）、重置小窗。
- 未做：捕鱼计数与结算、手竿计时、Steam 房间与同图好友（网页版房间面板只有本人）、高 DPI/多屏/负坐标（网页里由等比缩放代替，TECH-08/09 留给 PC 端）、声音。
