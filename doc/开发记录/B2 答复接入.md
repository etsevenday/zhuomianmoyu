## 2. 取舍

- **开发注入的鱼不算新鱼**：02 §2.1 说新鱼来自正常捕获，开发入口注入的鱼不加角标。
- **置顶默认开、后台输入默认关**：答复没写默认值，按 PC 版的预期默认（置顶开、后台收输入关）。两个都只是演示状态。
- **手竿保存频率**：只涨时间时 5 秒存一次，刷新最多丢最后几秒（不补离线本来就会丢）；出鱼马上存，鱼不会因为刷新丢。
- **开发入口**：`moyuDev.skew(毫秒)` 把手竿计时看到的"现在"往后拨、`moyuDev.poleTick()` 立刻检查一次，和每秒的检查走同一条路径；只在 `?dev=1` 下有。拨过的时间会写进那条鱼的捕获时间，所以验收脚本造出来的手竿鱼时间在"未来"，只影响开发档。
- **未拥有的外观仍写名字**："？"只给未发现的鱼（定稿 §1），外观格子写名字加"未拥有"。
- **面板排版**：设置面板改成左边四个开关、右边说明；皮肤面板加描述和说明后整体压紧一点；鱼篓"已选 n 条"放到标题栏右侧。都在原面板尺寸内，不溢出。
- **B0/B1 用例**：B0-42"只有两行"、B1-07"计时未开放"、B1-30"游在水里"、B1-52"轮廓和出处"按答复作废，用例表里改写预期并标"B2 改"；B1-31、B1-47、B1-53 只改脚本取数（体长前加了"体长"、公示换成定稿句、没抓到的鱼不再显示鱼形）。

## 3. 没有接入的定稿句（COPY-FINAL-04）

定稿 §10 写明不因为列了提示就加弹窗或新功能。下面这些没有对应的界面状态，本批不接；以后有了对应状态再按原句接。

| ID | 原句 | 原因 |
| --- | --- | --- |
| TXT-B0-017 | 已选择 | 地图选完立刻切换，只有"当前地图"一种状态 |
| TXT-B0-019 | 这里不是当前玩法的可用位置。 | 放不下时已有 TXT-B0-018"这里放不下"；定稿 §2 说不在每次空白点击后弹 |
| TXT-B0-020 | 正在安排位置… / 暂时没有可用位置，请重试。 | 网页的自动安排是同步算出来的，没有等待和失败状态 |
| TXT-B0-021、022 | PC 缩放帮助、最小尺寸 | 仅 PC 显示，原生 PC 另做 |
| TXT-SET-006 | 当前未接收页面输入。 | 网页不检测"有没有焦点"，只按收到的真实事件计数，没有这个状态 |
| TXT-BASKET-004 | 已售出 | 鱼篓、收藏只列在手里的鱼，已售出的鱼不再显示（"鱼篓""鱼缸一"已用） |
| TXT-SALE-007 | 请先把这条鱼取回鱼篓，再出售。 | 收藏里的鱼不在出售列表里，选不到 |
| TXT-SKIN-003 | 预览 / 查看内容 | 点格子就直接在左边出预览，没有单独的"预览""查看内容"按钮（同组的"装备""抽取"已用） |
| TXT-SKIN-010、011 | 抽取确认 | B1 起抽取没有确认框，本批不加弹窗（定稿 §10） |
| TXT-SKIN-018 | 外观资源尚未准备好，本次未扣除金币。 | 外观全是内置 SVG，不存在资源未就绪 |
| TXT-SKIN-019 | 正在处理，请稍候。 | 处理中用底栏保存状态"保存中"（TXT-SAVE-001）表示，不另显示 |

## 4. 测试结果

推送前对本地 Release 包（da34200+改动）：内核 NUnit 127/127；`b2.mjs --release` 37/37；回归 `b1.mjs --release` 62/62、`b0.mjs --release` 47/47。变异测试（Stryker.NET 4.14.2）`--since:origin/main` 432 个、全量 483 个，幸存都是 0。

开发版首跑查出一处实现错（B2-10）：刷新后计时锚点要等第一次每秒检查才建立，读好档到第一次检查之间最多约 1 秒不计；改为读好档立刻检查一次。详见[用例表](<../测试用例/B2 答复接入.md>)运行记录和失败归类。
