## 1. 工程映射

| 规则 | 实现 |
| --- | --- |
| 采集程序（`pc/input/`） | C# 控制台程序 `MoyuInput.exe`，外壳传小窗的窗口句柄给它。用 Raw Input 注册键盘和鼠标，带 `RIDEV_INPUTSINK`（不在前台也收得到），挂在一个只收消息的隐藏窗口上。不装钩子：Raw Input 只是旁听，不拦截、不改写，原输入照常给用户正在用的程序。标准输出只有 `ready`、`k 0/1`、`c 0/1` 三种行 |
| 只数次数（§3、§6，PCI-11） | 不取字符、键名，不记按了哪个键、点在哪、在哪个程序里，不写文件、不联网，外壳也不写日志。"这个键是不是还按着"只在采集程序内存里记到松开，用来去掉自动连发；采集程序退出就没了 |
| 按键口径（§4.1） | 按下计一次；同一个键松开前再来的按下（自动连发）不计；松开不计；组合键里每个键的按下各计一次；输入法按真实按键计（采集的是键，不是上屏的字）。键盘驱动补发的假键（`VKey=0xFF`、NumLock 下的假 Shift）不计 |
| 点击口径（§4.1） | 左、右、中、两个侧键任一按下到松开算一次；按下后指针离开超过 5 个逻辑像素（按那块屏的 DPI 换成物理像素）就算拖，不计；移动、滚轮不计。位置用这条输入发生时的指针位置（`GetMessagePos`），不用处理时的 |
| 游戏操作排除（§4.2，PCI-05） | 键盘：按下时前台是小窗自己就不计（键盘焦点在游戏菜单里时的输入也排除）。点击：按下处的窗口是小窗自己、而且小窗这时不是穿透的，就不计；穿透时点击实际落到下层，照算。面板、选位、拖窗、缩放、收起、恢复、设置开关、退出都在小窗身上，天然排除，不先加后减 |
| 不双计（§4.2） | 只有一条通道：PC 模式下页面自己的 DOM 事件一律不计（B4），只认外壳转来的。外壳每收到一条立刻转给页面，页面和网页版一样每次调用一次 `OnWorkInput`，不合并、不限速 |
| 序号与重试（§3、§4.4） | 采集程序 → 外壳 → 页面都是进程内按顺序送达，没有重发路径，同一事件不会到两次，所以没有另加序号。模式/地图边界：每条到达时立刻按当时的模式、地图记（保存事务进行中先排队，排队时就记下模式、地图，B1 已有） |
| 真实开关（§4.3，PCI-01、PCI-09） | PC 自己的偏好存在数据目录 `input.json`：`{ version, on, chosen, introShown }`，和网页（及 B4 时）的演示开关 `Settings.BackgroundInput` 分开，互不覆盖。没有这个文件就是"没有真实偏好"，默认开；玩家点过开关就记 `chosen`，以后重启照玩家的选择 |
| 实际状态（§3、§4.3） | 外壳记采集状态：已关闭 / 正在启动 / 正在采集 / 启动失败 / 中断 / 不支持（不是 Windows），推给页面。设置里那一行标签：开关关是"已关闭"，开着且真在采集是"正在采集"，开着但没在采集是"尚未采集"（TXT-PC-017—019）；正在启动、失败、中断、不支持在下面一行说明（TXT-PC-013—016），失败和中断带"重试"按钮 |
| 首次说明（§2，TXT-PC-007） | 只在"没选过、默认开、采集真跑起来"那一刻显示一次，用页面现有的浮出提示（3.5 秒自己消失），不开面板、不抢焦点。页面订阅前就跑起来也不丢：外壳记着，页面确认显示过才清；`input.json` 记 `introShown`，以后不再弹 |
| 开关提示 | 玩家打开：真跑起来再提示 TXT-PC-008；关掉：提示 TXT-PC-009，下面显示 TXT-PC-010。启动失败、运行中断用对应原句浮出提示（错误样式） |
| 关闭顺序（§4.3） | 关掉开关或开始退出（点关闭、Alt+F4 等）时，外壳先把采集程序标成"不认"，之后它再送来的行都丢弃，再结束进程；然后才走保存退出。重开不补关闭期间的输入 |
| 失败与中断（§4.3，PCI-10） | 采集程序起不来是"启动失败"，跑过又退出是"中断"，都不自动反复起，等玩家点重试；不补算没采到的时段，不用定时加数或开发注入代替 |
| 收起、遮挡、失焦、置顶（§2、§4.3） | 不改开关、照常计；只有退出才停 |
| 设置页其他说明（Q24） | 置顶行悬停提示 TXT-PC-003，后台输入行 TXT-PC-004；"输入说明"（TXT-PC-023）按钮展开 TXT-PC-004、005、006、011、012、020、022。网页照旧用 TXT-SET-004/005 |

没接的原句：TXT-PC-001、002、024 和现有的"置顶""后台输入""开/关"同字，照用现有的；TXT-PC-021"正在保存并退出…"是可选状态，PC 退出很快，没加。"重试"按钮字样沿用通用说法。

## 2. 取舍

- **Raw Input 而不是低层钩子**：钩子能拦截输入，钩子程序卡住时整个系统的输入都会卡；杀毒软件也更容易把它当键盘记录器。Raw Input 只旁听，不影响别的程序。
- **采集程序单独一个进程**：Electron 主进程不用碰原生模块，采集程序挂了不影响小窗，开关关掉时整个进程结束，"关着什么都不采"一目了然。
- **中断不自动重启**：定稿给的是"已中断，请重试"，自动重启会让状态说不清；先等玩家点重试。真人试玩如果觉得中断太常见再议。
- **运行时**：`MoyuInput.exe` 现在按依赖框架发布，要装 .NET 8 运行时；做安装包时改成自带运行时发布。

## 3. 不支持（待人工 B5-M4 确认）

锁屏、UAC 弹窗（安全桌面）系统不让任何程序读，收不到是预期。以管理员身份运行的程序、远程桌面里的程序、独占输入的全屏游戏能不能收到，待人工确认后补在这里。

## 4. 测试方法

`tools/verify/b5.mjs` 以测试模式启动外壳（`MOYU_TEST_OS_MOUSE=1`：系统鼠标照常进窗口，B4 测试模式下是挡掉的；不预写 `input.json`，等于全新安装），开一个记事本垫在小窗底下，用 `tools/verify/sendinput.ps1` 发系统层面的按键和点击：

- 发键前确认前台就是指定窗口，点击、拖动前确认那一点上的窗口就是指定窗口，不对就停下报错，不会往别的软件里打字或点击。穿透用例借这个守卫顺便验证：点之前那一点上的窗口已经是记事本，说明小窗在系统层面真的让开了。
- 按的是数字 1：中文输入法开着时字母会进拼音组字、到不了记事本，数字直接上屏。
- 挪指针用 `SendInput` 的真实移动，不用 `SetCursorPos`：后者不算输入，小窗收不到转发的移动，不会按指针位置切穿透。
- 脚本文件存成带 BOM 的 UTF-8，Windows PowerShell 5.1 才不会把中文读乱。
- 启动失败用 `MOYU_INPUT_EXE` 指向不存在的文件。

b4 只测窗口，启动前预写"玩家关过后台输入"，免得测试机上的系统输入混进来。

跑的时候不要动鼠标键盘，会混进去。

## 5. 运行

```bash
cd pc
npm install
npm run build
npm start
```

`npm run build` = `build:web`（网页包）+ `build:input`（采集程序，`dotnet publish` 到 `pc/.input`，不入库）。
