# PC后台输入与开关

系统编号：PC-INPUT-001；单案修订：0.1；更新日期：2026-11-18。
规则状态：用户已完整答复Q23/Q24；PC全局输入规则与本轮逐字文案已定，系统采集尚待开发接入，不以B4窗口测试替代输入验收。

## 1. 目标、职责与边界

解决“在其他程序工作时，游戏不增加动作和计数”的问题。对现有Electron PC外壳接入Windows系统级键鼠动作计数，继续复用既有角色、计数、节点与个人存档，不把输入事件发到房间或其他玩家。

现有基线dc89e6a：B4已有透明无框、真实置顶、拖窗、16:9缩放、收起恢复和存档退出；PC页面输入全部按游戏操作排除，后台输入开关仅保存状态，尚不驱动路亚/摸鱼。[B4开发记录](<../../开发记录/B4 PC 窗口.md>)、[B4用例](<../../测试用例/B4 PC 窗口.md>)。新规则不意味着这些系统级输入已实现。

网页版仍只接收当前页面实际收到的游戏UI以外输入，后台输入/置顶为演示状态；不能用本PC方案宣称普通网页已能收其他程序输入。安装Windows助手桥接网页仍是先前issue #8的评估候选；本次Q23明确推进已有PC壳的输入能力，不代用户关闭或宣布助手评估已完成，也不让该评估阻塞已答PC规则。

结构化规则见[PC输入参数](<assets/PC输入参数 v0.1.json>)，仅为策划资料，不修改运行配置。

## 2. 玩家流程

启动PC游戏 → 加载独立PC偏好及玩法档 → 无真实开关偏好时后台输入默认开 → 系统采集实际启动成功后显示一次非打断说明 → 切到其他程序正常工作 → 当前角色动作/总累计/当前模式周期推进 → 保存确认后的鱼获进入个人鱼篓。

玩家在设置中可随时关闭/再次开启后台输入；关闭立即停止新增系统输入资格，已有进度与资产保留。之后重启恢复玩家真实选择，不能每次启动又强制开启。用户已选默认开，不增加“先手动开启才生效”的首轮阻塞。

收起为头像、窗口被其他应用遮挡、失焦或置顶关闭不等于关闭游戏，后台输入保持按开关执行；退出程序停止。首次提示只在真实功能首次启用且实际成功时出现，不抢其他程序焦点、不开设置大面板；失败显示失败状态，不能提示已启用。

## 3. 对象与主数据

| 对象 | 语义字段／初值 |
| --- | --- |
| 后台输入偏好 | PC真实开关、设置版本/首次接入标识；无真实设置时默认true，有真实选择则恢复 |
| 采集实际状态 | 未启动／启动中／运行中／已关闭／失败／正在退出；开关意愿与运行结果分开 |
| 规范化输入 | 本地事件序号、类别（键盘按下/鼠标点击）、临时路由代次；每次接受增量1，或保序批次中的精确数量 |
| 游戏控制状态 | 当前模式/地图、已确认位置、收起/退出、UI手势归属、玩法档就绪/写权 |
| 重试/去重 | 本地会话及递增序号、路由/模式地图边界、已消费序号；不含键名/字符/点击坐标/应用名 |

原始键标识或指针命中信息如为去repeat/游戏热区过滤所必需，只允许在适配层内存临时判断；不落盘、不发给网页玩法、日志或房间，不转成输入文字或软件使用记录。无需保存逐键时间线。程序退出、采集重启或状态失效时清临时按下状态，防止长按状态遗留。

## 4. 规则与结算

### 4.1 计数口径

开启且采集实际运行、玩法档可写时，游戏自身管理以外的真实键盘按下和鼠标点击各计1；适用其他程序，包括浏览器窗口中的普通操作，不要求PC游戏获得焦点。键盘repeat/松开不计，组合键各真实按下分别计；输入法按真实按键计，上屏字符不重复加数。鼠标主/中/次键有效点击按原规则识别，移动/滚轮/保持/取消/已判拖动均不计。

只统计，不拦截、屏蔽或替用户输入；不新增50毫秒合并、每秒20次上限或后台收益折扣。不能承诺完全识别所有脚本/硬件宏，也不因反作弊修改本批既有数值。

### 4.2 游戏操作排除与去重

PC采用一个规范化工作输入入口接收系统适配层的有效动作；渲染页面的同次DOM/鼠标事件不再作为第二份捕鱼输入。普通网页仍用现有isTrusted页面事件，两平台不得靠伪造DOM事件互相补输入。

游戏实体、面板/菜单、开发控制、角色选位、拖窗、右下角缩放、收起头像/恢复、设置开关、退出、系统窗口管理等操作全部排除，包括按下到释放/取消及由其衍生的点击。不能先加数再回滚，也不能用整段额外冷却吞掉无关工作输入。

开启透明穿透时，透明留白中实际交给下层工作程序的有效操作可计1；相同屏幕坐标若实际被游戏截获则不计。不能仅以小窗外接矩形把所有下层操作都排除，也不能仅按“鼠标在窗外”忽略键盘焦点在游戏菜单中的管理输入。命中与坐标/DPI换算由开发实现并以真实桌面验证。

### 4.3 开关、状态和旧偏好

- 无真实后台输入偏好的首次使用默认开，启动成功才显示“已开启”与运行状态。旧B4/网页的演示开关值不等于真实采集设置，接入真实功能时使用PC独立版本/标记建立默认开；不把旧演示默认false误当玩家已对真实功能关闭。
- 一旦玩家在真实功能中明确关过或开过，后续更新/重启都保留该选择；关闭后台输入不清总累计、各图周期、鱼、金币、收藏或外观。PC与网页的演示偏好不能互相覆盖。
- 关闭操作先切断新增输入资格，再停止/注销采集；已在关闭前接受的事件按既有顺序完成一次，关闭后或旧会话迟到的事件不作为新输入。重开不补发关闭期间的系统输入。
- 收起/遮挡/失焦/置顶变化不自行改变后台输入开关；系统锁屏/睡眠等不可用时段不补造输入，恢复时重新建立临时输入状态，不回放积压动作。退出开始即停止新增采集资格，再按现有保存流程退出。
- 开关为开但系统适配失败时显示“启动失败/未采集”的真实结果，不假称正在累计；可主动重试。不得用后台定时加数或开发注入代替未接通的系统输入。

### 4.4 模式、地图、动作与资产

每个已接受输入固定归属当时的一个模式/地图，按现有顺序推进总累计与当前周期；批量交付仍逐个跨过节点，不能跳过或重复结算。模式/地图切换前后须有明确本地序列边界，旧事件不全部错投到新模式。

路亚500次50%、累计1000必中；摸鱼每200至1800判20%、2000必中；成功清当前周期而总累计不清，均保持既有规则。手竿时系统输入只加总累计/手竿输入统计和装饰反馈，不加速30分钟，不推进另两种玩法。高频动作可融合，不减少真实接受数，不排长动画补播队列。

同一规范化事件/重试序号只处理一次；捕获结果、周期和统计原子保存，失败重试不重抽/多发。原档加载失败/只读时不产生未经确认的收益，不把后来恢复可写当成可补造失效期间输入。

## 5. 手竿和PC界面（Q23③/Q24）

PC手竿在程序有效运行且当前模式为手竿时，收起或被其他窗口完全遮挡仍计时，退出停止；后台输入开或关不决定手竿是否计时。继续沿用Q8按图保存、30分钟、多余有效时间保留、超过5分钟检查间隔整段排除与无离线补算，不把睡眠/退出时间算作普通遮挡时间。

设置保留真实置顶和后台输入开关、状态与输入范围帮助；网页专用TXT-SET-004/005在网页继续原样，PC改用[PC逐字文案05](<../文案交接 v0.1/05 PC输入与设置文案定稿.md>)。网页假桌面角落TXT-SET-009/010不搬到PC透明画面。PC缩放只用光标，不新增悬停文字；旧03的TXT-B0-021/022原句保留作历史/备用，不作为本批必须显示的提示。

## 6. 实现接口、隐私与保存

系统监听API/本地组件、Electron主进程与渲染通信、设备区分/重复过滤由开发选型。本批不指定第三方输入库；必须验证现有Electron版本与目标Windows环境，不把普通DOM监听或窗口穿透成功当作全局采集成功。

系统适配只输出最小动作类别/数量和本地去重标识，玩法和房间不需要原始按键。开发/错误日志同样不得包含键名、文字、坐标或软件名；公开诊断只可含启动结果、匿名计数和版本。采集服务只在本游戏运行期间工作，不新增随Windows登录自启、独立常驻助手或其他客户端桥接。

当前网页与PC存档位置不同，沿B4既有安排保留，不在本批引入云同步、互相搬档或把两个客户端资产相加。“前后台不双计”指同一PC实例输入管线，不能假装已经实现跨两个独立存档的全局合并。

## 7. 联动与范围

本规则取代旧UI/玩法/技术文件中“PC全局输入仍待定”的当前状态，以及B4开关只保存演示值的阶段状态；旧开发记录/处理结果保留，由开发接入新结果后更新。网页只收页面输入的规则不变，助手可行性评估不视为已完成。

本轮不重做窗口、不要求接Steam真联机或打安装签名包，不更改4人房间/好友表现、不改经济和容量。B4人工透明/穿透/焦点/真实DPI/多屏检查仍需完成，系统输入必须追加真实跨程序验证。
