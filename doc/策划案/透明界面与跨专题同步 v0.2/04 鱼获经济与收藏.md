# 鱼获经济与收藏接口修订

系统编号：ECON-001；单案修订：0.2；更新日期：2026-11-16。
规则状态：已选界面的流程修订；经济平衡与资产状态细则仍为参考扩展。

## 1. 目标、职责与边界

保持轻量工作陪伴：鱼获出现不强制中断工作，玩家主动打开鱼篓决定去向。用户已定出售、收藏、游戏币抽外观和买鱼缸，不由本版图定容量、售价或抽取机制。

## 2. 玩家流程

已成功捕获 → 保存个体结果 → 简短提示 → 继续工作或主动打开鱼篓 → 选个体 → 发起出售/收藏请求 → 接收明确结果。

收藏入口用于容器与展示管理；记录入口用于历史/尺寸查看；皮肤入口位于更多菜单。管理动作不推进捕鱼输入。

取消、关闭面板或点击透明外部不等于出售、不等于放入收藏，也不删除鱼。穿透开关开启时，面板外留白应能操作下层桌面。

## 3. 对象与主数据

| 对象 | 本次所需语义 |
| --- | --- |
| 鱼获个体 | 唯一ID、鱼种/外观、体长与单位、归属、当前持有/位置状态 |
| 鱼篓视图 | 当前可整理的持有个体、选中ID、操作资格及禁用原因 |
| 展示容器 | 容器ID、容量规则/余量接口、已放个体、背景选择、统一展示尺度 |
| 出售 | 请求/事务ID、个体ID、估值与版本、金额、提交状态 |
| 记录 | 捕获历史与当前持有分开，历史项不是可再次出售的资产 |
| 外观 | 浏览类别、外观ID、拥有/装备状态；抽取池与类别是不同字段 |
| 抽取/扩容 | 条件、成本、规则版本、请求状态、结果；未定不能假扣币 |

本表是防止UI耦合错误的接口需求，不批准旧背包/暂存/撤销状态机。

## 4. 规则与未定结算

三模式互斥；收益预算不能把同一时段的主动模式和手竿相加。原经济草案的主动/手竿分时样例不与互斥冲突，但样例时长、输入速率、均价和出售比例仍未确认。

旧草案的8条鱼缸、30条背包、400/800扩容、240单抽、75%/20%/5%概率、20抽保底、48重复返还和30秒撤销均未获批准。本版不将它们写入开发配置。

分类页签只表达可分类浏览；不代表4个分类池、独立保底或选中鱼竿就只出鱼竿。抽取池的含义/成本/概率定稿前，不实现真实扣币抽取。

保存去向、满容量承接、收藏鱼转售、锁定与撤销均仍待定。界面不能因规则未定先静默丢弃捕获，也不能擅自引入无限背包或自动出售。依赖这些规则的真实资产处理不在本轮UI接入范围内。

## 5. UI与文案

鱼篓要表达：选中了哪条鱼、大小、估值是否可用、两种去向、操作是否可执行。收藏要表达：当前容器、鱼只、展示预览、余量与扩容入口。空列表、无容器、容量不足、余额不足、已售出、重复请求和提交失败应有准确状态。

皮肤要表达：浏览类别、预览对象、已拥有/装备、成本和规则、抽取结果；规则待定不能显示为免费。文案需求均【交文案策划定】，图片中的字只作排版占位。

## 6. 事务、存档与防错接口

以下是资产设计必须维护的防错约束，具体事务实现由开发方选择，完整状态机待资产规则定稿：

- 同一个体不能被复制到两个鱼缸或再次完成出售到账。
- 捕获事件重发、重复点击、关闭面板不能重复发鱼/扣币/到账。
- 提交中禁用该操作或返回同一请求结果，失败不出现半完成的展示。
- 展示引用真实个体；历史记录与当前持有不能混作可操作资产。
- 改背景和移动窗口不改变鱼的尺寸数据和归属。
- 已知容量不足时不能先删来源个体；落点规则未定则不执行该操作。

不因本轮文档上传修改已有用户存档；仓库尚无实现存档。

## 7. 跨专题冲突登记

- 地图专题曾建议按鱼种占格，经济专题建议按条数，总策划提固定槽位：容量单位仍未统一，不取某张图代替裁定。
- 好友是否能浏览个人收藏：经济有公开展示接口草案，技术曾建议首版不支持；仍待范围裁定。
- 皮肤是否纯外观、是否改变地图/鱼池：不从“场景”页签自行推导。
- 鱼篓入口不等于批准独立背包加无限暂存架构。

## 8. 验收目标

- ECON-01：成功捕获不自动打开处置面板；关闭提示后个体仍可被查询。
- ECON-02：出售/收藏只由主动操作触发，关菜单不触发去向。
- ECON-03：任一时段只有当前模式产生收益。
- ECON-04：分类页签、示例鱼缸数、成员数和样例鱼长不写成经济参数。
- ECON-05：重复请求不重复改资产；失败不显示假成功。
- ECON-06：记录页不能再次出售已无持有资格的历史个体。
- ECON-07：在16:9小窗里可选择鱼并看到操作条件；未知数值仍标待定语义。
- ECON-08：菜单/拖动不增加捕鱼计数；透明外部点击按用户穿透开关处理。

## 9. 待定与来源

所有经济参数、容量、暂存/背包、收藏鱼再出售、撤销、外观属性/池子均为原专题待定。来源为经济收藏会话和00本轮裁定；本次只替换流程/窗口/互斥依赖，不批准整篇经济试算。
