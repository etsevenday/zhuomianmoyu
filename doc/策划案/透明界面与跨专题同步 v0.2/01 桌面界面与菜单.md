## 1. 目标、职责与边界

在约整屏1/16的小窗中提供输入反馈和必要管理入口。画布始终16:9，可任意拖动，不再预设底部全宽或半屏档位。

PC版Q6/Q7已定：初始约1/16，之后可从右下角拖动自由缩放，最小400×225逻辑像素；保存玩家选择的占屏比例，换屏松手及下次打开时按当前屏恢复。网页固定尺寸不变。计算和恢复边界统一见[05 §6.1](<05 Steam联机与窗口验收.md#61-pc窗口尺寸与跨屏恢复q6q7>)。

透明是负空间，不是乳白半透明背景，也不是画进PNG的格纹。角色、工具、岸边、水面、主栏和卡片保持实体色；角色奶油色腹部与UI底色不能被按白色统一抠掉。

## 2. 玩家流程

正常使用电脑 → 当前模式的角色反馈 → 鱼获保存后出现轻提示 → 玩家主动打开鱼篓 → 选择出售或收藏，或关闭继续工作。

左下模式入口用于切换三种互斥玩法；顶右为房间、静音、收起、关闭。底部为当前模式、鱼篓、收藏、记录、更多；更多包含地图、皮肤、设置的功能入口。

不同功能面板由用户主动打开，同一时刻仅展示一个主要管理面板；打开另一个时替换原面板。关闭面板回到原场景和窗口位置。穿透开启时，透明外部区域不铺全屏拦截遮罩，点击那里交给下层应用。用户主动关闭穿透后可被窗口命中，但不新增拖动/按钮行为。

上述入口是功能语义，显示文字均【交文案策划定】。

## 4. 规则与结果

| 区域 | 视觉 | 指针行为 |
| --- | --- | --- |
| 透明留白、竿线内侧空隙 | alpha透明 | 穿透默认开启时交给下层桌面/应用；可关闭穿透，不拿留白拖动 |
| 角色实体、水面实体 | 不透明 | 按住拖动窗口；本模式可用岸边/浅水范围内的单击选位按09处理 |
| 标记为可用区域的岸面 | 不透明 | 单击按09为本人选位；区域边界与地图数据一致 |
| 植物、竿线及未标记为活动区域的岸景等纯装饰 | 按画面保留实体 | 不新增操作；不扩大成覆盖留白的矩形热区 |
| 主栏与独立右上按钮 | 实体底色 | 接收对应控件操作，不触发拖动或捕鱼计数 |
| 弹出面板与鱼获卡 | 实体底色 | 控件接收操作；面板不延展成全窗遮罩 |

角色/水面按下后先由交互处理，不先记一次捕鱼输入。单击本模式可用岸边/浅水范围时，在释放并确认为非拖动后发起一次选位；按住移动形成拖动时，仅移动整个窗口，后续释放/取消不再产生选位。两类操作均不增加捕鱼计数。拖动期间保持16:9，不改变地图、模式、计时政策或鱼获归属。位置恢复规则见05。

不增加九点柄或左上标题。拖动判定阈值、抗抖与指针形态属于实现细节，开发在保证上述语义的前提下选择。

PC版新增右下角缩放热区，只在用户从该区域开始操作时接收缩放，不把整个透明留白变为可命中区域；热区内缩放优先于选位/拖窗，不能同时触发面板按钮。缩放的按下、移动、释放/取消及后续点击均为窗口操作，不计捕鱼输入，不改变地图中角色落点或鱼体长。右下角热区的具体大小和指针形态由开发实现；若有玩家可见提示，语义为说明可拖动改变窗口大小，逐字内容【交文案策划定】。不采用三档大小菜单。

## 5. 菜单、显示与输入

| 入口/状态 | 显示事实与控件 | 行为边界 |
| --- | --- | --- |
| 模式 | 路亚/摸鱼/手竿三入口、单个当前状态 | 不展示其他模式正在产出；切换进度规则引用02 |
| 房间 | 本人/成员、邀请、离开、连接结果 | 邀请点击不等于好友已加入；空/满/失败状态由房间接口提供 |
| 鱼篓 | 鱼获个体、体长、选中详情、出售/放入收藏 | 无鱼时留空状态语义；失效选择或提交中不能重复操作 |
| 收藏 | 容器、鱼只、背景预览、设为背景、管理和扩容入口 | 余量不足、空缸或没有容器时说明原因；规则未定不假装成功 |
| 记录 | 鱼种列表、尺寸记录及选中鱼详情 | 未发现项不伪装成已捕获；售出记录与持有鱼分开 |
| 更多 | 地图、皮肤、设置 | 不恢复已删标题/九点；地图入口以更新图08为准 |
| 地图 | 三张地图的可选项、当前选中 | 名称/鱼池/解锁未定，地图不能当成场景皮肤 |
| 皮肤 | 四类外观筛选、预览、抽取规则/内容入口 | 筛选不等于分池；真实扣币依经济规则 |
| 设置 | 置顶、透明区穿透、静音、后台输入等状态 | 穿透开关保留，默认开且允许关闭；只改变命中，不改变alpha；其他开关的初值仍是建议 |
| 收起/恢复 | 缩为原位置可拖动圆头像，单击恢复 | 拖动释放不触发恢复，不因鱼获/好友事件展开；合格页面输入和手竿计时继续，关闭后停止 |
| 关闭 | 退出游戏的明确控件 | 先按资产接口保存；退出收益按既定规则，不能默认为离线奖励 |

无对象、无权限、空间不足、余额不足、请求失败、提交中等玩家可见提示，需按实际条件提供功能语义，均【交文案策划定】。文案未齐不影响只读布局验证；不以AI图中的字直接上线。

高DPI时按逻辑坐标排布、按物理像素正确渲染。保持16:9，必要时折叠次要信息、分页或滚动；不能把窗口撑成别的比例。窗口尺寸/文字/命中区域转换必须一致，不用图片的1672×941等取整尺寸作为窗口规格。

穿透关闭时，留白仍透明但可被窗口命中，不把它新增为拖动区或另设收益入口；空白点击是否属于有效捕鱼输入仍按02的待定输入资格政策，不能由开关状态推定。底部菜单与右上控制始终可操作，用户可回到设置重新开启穿透。开启后立即恢复下层点击；面板是否打开不改变开关设定。开关状态应随窗口设置保存。

## 6. 反馈、事务与存档

输入动作、成功、稀有、保底是不同展示层级：普通输入仅角色局部动作；成功使用短鱼获卡；稀有可加克制边框；保底只依据玩法标记。保底不等于稀有。

高频输入合并动作、水花和音效，不排长动画队列。多条鱼获可合并提示数量，完整个体仍进入鱼篓。关闭卡片、打开菜单或隐藏窗口不撤销已保存鱼获。

主界面不自动弹出出售/收藏决策。默认建议静音、普通输入无声、好友表现降噪；这些是建议配置，不代表本轮新增了获得概率。

窗口位置、当前面板可恢复性、声音等设置与玩法存档分开。旧版本若有标题/半屏偏好，不据此清空鱼获；迁移细节由实际版本确认。

- UI-01：1920×1080、100%缩放时参考窗口480×270，16:9且可放在任意可见位置。

- UI-03：角色/水面可拖动，UI按钮可操作；一段拖动不推进任何捕鱼计数。
- UI-04：左上无标题/九点，右上四个按钮有独立热区，不存在整条不透明顶栏。
- UI-05：更多能到达三地图选择，当前地图有单独选中状态；关闭后不切换模式。
- UI-06：管理面板实体底色可读，穿透开启时透明外围不成为拦截遮罩。
- UI-07：鱼获出现不夺取焦点、不要求立即处理；关闭提示后鱼仍在鱼篓。
- UI-08：高频输入停止后不继续播放长队列；表现合并不改变已保存鱼获数量。
- UI-09：收起/恢复保持比例与位置，无后台事件自动拉起窗口。
- UI-10：文字未定/无数据/提交失败时不执行假扣款或伪造成功。

- UI-11：穿透开关默认开；手动关闭后留白仍透明，角色/水面可拖、菜单可操作；重新开启后下层点击恢复，开关状态可保存。

## 10. 同图成员与选位联动

场景须实际显示同图好友及其当前模式动作；房间列表不能替代同屏角色。岸边钓鱼和浅水摸鱼提供连续可选范围，系统先自动安排。区域、占用、选位与表现归属的唯一规则见[09 同图多人选位与表现](<09 同图多人选位与表现.md>)。

好友收获锚定获得者的位置，表现合并时保留归属，不自动打开鱼篓/收藏或抢工作焦点。成员识别、位置不可用、正在安排及失败等提示的显示语义按09，逐字内容【交文案策划定】。

本次已定单击选位、按住角色/水面拖窗，§4与09同步生效。允许玩家尽量靠近，不额外拉开间距；目标确实放不下时保留最后确认位置并反馈，不以原建议的“最近合法位置”擅自替代用户选择。选位、确认、取消及拖窗均不推进捕鱼输入。

- UI-12：好友加入后能在场景看到其角色、当前模式动作和对应收获，不仅是列表头像。
- UI-13：单击连续可用区域选择位置，按住角色/水面拖动窗口；拖动释放不再选位，两类操作都不增加捕鱼计数。
- UI-14：不同玩家同时收获时仍可区分归属；操作面板关闭后显示最新成员位置。
- UI-15：PC版右下角拖动可自由缩放且保持16:9，最小400×225逻辑像素；缩放全程不选位、不拖窗、不触发按钮、不增加捕鱼计数。
- UI-16：PC版保存自选占屏比例，跨屏松手和重启后按当前屏恢复；具体数字与DPI场景按TECH-21—26验收。网页版没有因此新增缩放功能。
