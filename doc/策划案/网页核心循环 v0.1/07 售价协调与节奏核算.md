# 售价协调与节奏核算

资料编号：WEB-PRICE-REVIEW；修订：0.1；日期：2026-11-16。
状态：按用户“价格需要总结协调别的会话重新设定”的委托完成三专题复核与统一设定；不是用户逐项点选金额。节点、次数保存、六鱼池和100币抽取/20币重复返还/四次重复后的下一抽必新均不改。

## 1. 三专题结论与总控选择

经济、地图、总策划均推荐鱼种基准价＋同种相对大小浮动，反对只靠绝对厘米决定价值。三专题建议的平均售价节奏不同：

| 来源 | 平均售价／条 | 取舍 |
| --- | ---: | --- |
| 经济收藏初轮推荐 | 17.8币 | 较慢积累，首抽需更多售鱼 |
| 地图鱼类推荐 | 31.6币 | 中档积累，保留目标鱼单次惊喜及同种大小价值 |
| 总策划初轮推荐 | 约47.2币 | 更快首抽，有限12款外观消耗较快 |

总控按委托统一采用中档31.6币：04 §1.1基准16／24／60／150，浮动4／6／15／30。三种专属鱼共用150基准；各鱼种内部按相对体长定价。经济、地图、总策划均对该表与计算完成最终复核。原来每厘米1/2币或每条100币退为历史。

取舍：同种更大更值钱；跨鱼种不保证绝对更长一定更贵。三图长期均价一致，玩家可按专属鱼和背景偏好选图。只改价格，不改已定鱼池、尺寸、捕获成功率、输入口径或抽取规则。

## 2. 逐毫米核算与地图均价

按已定含端点、1毫米步长尺寸逐值计算，04的整数公式满足：价格单调不降，最小/中点/最大值正确，中点两侧对称取整，各鱼种均价精确等于基准。

```text
每图期望售价
= 40% × 16 + 40% × 24 + 16% × 60 + 4% × 150
= 31.6币
```

直接按绝对厘米且向下取整时，M1/M2/M3分别约16.477／17.277／18.677币；第三图约比第一图高13%。统一推荐消除该固定地图收入优势，但保留不同物种的实际观赏尺寸。

原始枚举结果见[售价核算记录](assets/售价核算记录.json)。这是策划公式与节奏核算，没有运行游戏或宣称实现通过。

## 3. 首抽与长期收入情景

假设：新档0币，空周期开始；持续同一主动模式；输入以表中恒定有效速率到达；鱼种/尺寸与节点随机独立；全部鱼立即出售；无收藏留存、其他消费、暂停、跨组分散输入、赠币或网页外输入。60／120／240次每分钟是假设，不是用户实测。

首抽采用余额首次达到100币的递推：E(0)=0，E(c)=1＋Σ[p<c] P(鱼价=p)×E(c−p)，c为仍缺的整数金币。三图都约需出售4.0979条鱼；不直接以100÷均价替代首次达标问题。

| 有效输入／分钟 | 路亚首抽期望 | 摸鱼首抽期望 | 路亚长期金币／小时 | 摸鱼长期金币／小时 |
| ---: | ---: | ---: | ---: | ---: |
| 60 | 51.2分钟 | 61.0分钟 | 151.68 | 127.44 |
| 120 | 25.6分钟 | 30.5分钟 | 303.36 | 254.89 |
| 240 | 12.8分钟 | 15.2分钟 | 606.72 | 509.78 |

路亚每鱼期望750次输入；摸鱼892.6258176次。本表“长期”收入不是从空周期开始的首小时精确收入。首抽为数学期望，不保证每次在该分钟出抽，也不保证4条鱼必定够100币；保留收藏、低输入或停用网页会延后。

## 4. 已定重复抽取的币量核对

拥有k款时，普通抽重复概率q=k/12；最多连续4次重复后，第5抽必新。因此得到下一款的期望抽数为1＋q＋q²＋q³＋q⁴。

| 指标 | 结果 |
| --- | ---: |
| 从0款到12款的期望抽数 | 25.46248抽 |
| 期望重复次数 | 13.46248次 |
| 期望净金币消耗 | 2276.99846币，约2277币 |
| 最少抽数／净消耗 | 12抽／1200币 |
| 最差抽数上限 | 1＋11×5＝56抽 |
| 最差重复数／净消耗 | 44次／4720币 |

净消耗=100×抽数−20×重复数。抽前仍须有100币，不能预借重复返还。2277币是平均值，不是包抽齐预算；56抽上限只适用于固定12款池、已定规则完整保存且未另加内容的条件，不承诺固定游玩时长。
