# 输入计数与节点捕获

系统编号：WEB-INPUT-001；修订：0.1；日期：2026-11-16。
规则状态：WEB-DEC-02/03/04/07/09已定；节点、各地图各玩法记住次数、六种临时鱼池均按正文执行。

## 1. 输入归属与单次计数

页面实际收到的游戏UI以外工作输入作为候选，包含模拟桌面、图标、记事本和其他页面内工作区域，不仅监听记事本。游戏小窗/菜单/面板/选位/拖窗/收起头像/恢复入口/出售收藏/抽取装备等管理操作均排除，位置在模拟任务栏也不改变其游戏管理归属。

- 键盘每次真实按下计1；长按自动repeat不加数；按键松开不计。
- 组合键的各个真实按下分别计数，不做50ms合并，不新增每秒20次上限。
- 输入法按真实键盘事件计数，不再按composition、beforeinput、input或上屏字符数重复加数；未收到的按键不按字符长度补算。
- 鼠标一次真实点击计1，不对同一次操作的pointerdown/up/click/dblclick重复加数；双击中的两个独立点击可各计1。移动、滚轮、保持、取消及已经判为拖动的操作不作为点击。
- 页面失焦/隐藏后没有收到真实事件时，不能补造输入或自动回放；恢复焦点本身不算输入。
- 仅处理事件是否发生及其管理归属，不保存、上传键入文字、字符序列、剪贴板或应用标题。

鼠标按页面实际收到的真实主/中/次键点击识别，保持浏览器正常行为；浏览器未投递的事件不补造。穿透关闭而被游戏窗口截获的留白点击属于游戏区域，继续按游戏管理来源排除。不能拿B0拖动后300ms点击屏蔽当成新的捕鱼输入冷却；一次拖动只排除其自身衍生点击，不添加游戏输入合并窗口。

## 2. 统计与周期分开

| 字段语义 | 用途 | 变化规则 |
| --- | --- | --- |
| 累计有效工作输入 | 回答总共输入了多少次 | 初值0，已接受输入加1，出鱼/切模式不归零；同档刷新恢复 |
| 各模式累计输入 | 统计在哪种模式下输入 | 只增加接收该事件的模式，切换和出鱼不归零 |
| 路亚本轮进度 | 500/1000节点 | 当前模式为路亚时加1，成功后归零；失败保留 |
| 摸鱼本轮进度 | 200至2000节点 | 当前模式为摸鱼时加1，成功后归零；失败保留 |
| 手竿有效时长 | 30分钟基线 | 不由键鼠输入推进；完整计时政策另定 |
| 事件/周期标识 | 去重、保存与恢复 | 同一输入、节点、捕获事件不能重复处理 |

一次已接受事件只归当前一个模式。先固定该事件的模式/地图及序号，再更新统计与当前周期，产生动作请求；不从动画播放次数反推计数。手竿期间的统计和装饰动作不得推进路亚/摸鱼周期。

累计统计与当前周期字段从本轮功能生效后建立，不能从B0示例鱼或曾经的按键历史反推并补发鱼获。

## 3. 用户已定的节点顺序

### 路亚

本轮累计到500次时进行一次50%判定，成功生成1条鱼并将路亚本轮进度归零；失败保留500继续累计，到本轮累计1000次直接生成1条鱼并归零。不是在失败后的500基础上再追加1000次。

### 下水摸鱼

本轮累计在200、400、600、800、1000、1200、1400、1600、1800各节点作一次20%判定；成功生成1条鱼并归零，失败继续。前九次均失败则2000次直接生成1条鱼并归零；2000次不再同时做20%抽取，避免双奖励。

### 共同规则

非节点输入仍有即时拉竿/探水动作及计数反馈，不进行额外随机出鱼；成功即进入鱼获资产层，不加QTE或第二层随机失败。普通动作、咬钩/成功表现和鱼获保存是不同状态。

在独立随机且成功后归零的已定节点模型下，路亚长期期望每鱼750次有效输入，摸鱼为200×(1−0.8^10)/(1−0.8)=892.6258176次；最差分别1000/2000次。此为每鱼输入期望，不是承诺几分钟一鱼，实际时间取决于有效输入速率。

## 4. 计数、动作、出鱼与保存

输入资格通过 → 去重并固定事件归属 → 累计统计/当前周期更新 → 发出即时动作请求 → 达节点时只判定一次 → 生成鱼获及对应周期结果 → 保存完整结果 → 发布鱼获成功提示。

动作可以先对已接受输入立即反馈；正式鱼获、金币与皮肤等资产结果须以成功提交的存档事务为准。保存失败不能假称已永久得到鱼；必须保留可重试的同一事件结果，不能重试重抽，不能加了鱼却未重置周期或反过来。

动画卡顿、合并、高频短促重触发不减少计数；停止输入后不得长期补播普通动作。出售、抽取等管理操作的动画也不能产生新的有效输入。

## 5. 各地图、各玩法分别记住次数

用户已定：按“模式×地图”分别保存本轮输入，切走暂停，切回继续。例如地图一路亚400次，换去地图二后地图二使用自己的路亚次数；再回地图一仍从400次开始。切摸鱼也只使用该地图自己的摸鱼次数，路亚那400次保留。

同一组成功后只把这一组本轮进度归零，其他组不变，历史总数不变。按已确认的六种临时鱼池及尺寸生成个体，捕获使用这组周期对应的地图，不能借切图把一份临近保底结算到另一图。

## 6. 计划验收

- WI-01：页面内多个非游戏区域的同样输入均能触发当前模式动作和计数，不只记事本有效。
- WI-02：按下/释放、输入法提交、事件冒泡和双通道回调不重复加数；长按repeat不加数，组合键各真实按下分别计数。
- WI-03：一次选位、拖窗、出售、收藏或抽取的完整管理操作，计数增量为0。
- WI-04：路亚499→500失败保留500，继续到1000只获1鱼；500成功则下一周期从0起算。
- WI-05：摸鱼200—1800失败路径到2000只获1鱼；2000不触发普通抽取和保底双奖。
- WI-06：出鱼重置当前周期，总累计及历史统计不归零。
- WI-07：低帧率和高频输入时计数结果一致，动作停止后无长队列；资产不依赖动画结束才保存。
- WI-08：切到其他软件打字不伪造页面输入；演示后台开关不改变能力边界。
- WI-09：同一捕获保存重试、刷新恢复和重复消息不再次抽鱼或发鱼。
- WI-10：一次传入多个已接受输入时，按原事件顺序逐个越过节点/成功后的新周期；不能一次加总而跳过节点，也不能将切模式前后的输入全部归到最后模式。
