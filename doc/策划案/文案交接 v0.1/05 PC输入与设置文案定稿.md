# PC输入与设置文案定稿

资料编号：PC-COPY-001；修订：0.1；日期：2026-11-18。
状态：用户Q24明确授权总控根据Q23补齐PC置顶、后台输入、输入范围及首次提示，整批归档推送；本表为该具体授权的接入原句，不记为shioko0315本人确认，不改其归属规则。

## 1. 平台和状态合同

规则见[PC后台输入正文](<../PC输入 v0.1/01 PC后台输入与开关.md>)。PC真实置顶与系统输入采用本表，网页仍原样使用03的TXT-SET-004/005。PC不画假桌面和网页角落说明，不搬用TXT-SET-009/010；Q24确定缩放仅光标，03的TXT-B0-021/022不在本批新增显示。

首次默认开说明必须等系统采集真实运行后才显示，不能因偏好为true就冒充已启动；不抢其他程序焦点、不强开设置。用户真实选择关闭后不再弹“默认已开”的首次话术。保存、鱼获、金币、记录和通用取消/重试继续复用既有逐字文案。

## 2. PC设置与首次说明

| ID | 位置／条件 | 逐字原句 |
| --- | --- | --- |
| TXT-PC-001 | 设置项 | 置顶 |
| TXT-PC-002 | 设置项 | 后台输入 |
| TXT-PC-003 | PC置顶帮助 | 开启后，游戏小窗会保持在其他普通窗口上方。 |
| TXT-PC-004 | PC输入范围帮助 | 开启后台输入后，会统计游戏界面以外的键盘按下和鼠标点击次数，用于角色动作和捕鱼进度。 |
| TXT-PC-005 | 隐私帮助 | 只统计次数，不保存键名、输入文字、点击位置或软件名称。 |
| TXT-PC-006 | 操作排除帮助 | 游戏菜单、选位、拖窗、缩放和收起恢复操作不计入捕鱼次数。 |
| TXT-PC-007 | 首次默认开启且实际成功 | 已开启后台输入，将统计游戏界面以外的按键和点击次数。可在设置中随时关闭。 |
| TXT-PC-008 | 已真实运行 | 后台输入已开启。 |
| TXT-PC-009 | 用户关闭后 | 后台输入已关闭。 |
| TXT-PC-010 | 关闭说明 | 关闭后，路亚和摸鱼不再累计工作输入；已有进度保留。手竿仍按有效时间计时。 |
| TXT-PC-011 | 收起／遮挡说明 | 收起或被其他窗口遮挡时，后台输入仍按开关运行。退出游戏后停止。 |
| TXT-PC-012 | 手竿PC说明 | 手竿在收起或被遮挡时继续累计有效时间，退出停止，不补离线时间。 |

## 3. 真实状态与失败提示

| ID | 位置／条件 | 逐字原句 |
| --- | --- | --- |
| TXT-PC-013 | 采集正在启动 | 正在启动后台输入… |
| TXT-PC-014 | 采集启动失败 | 后台输入启动失败，当前没有采集工作输入。请重试。 |
| TXT-PC-015 | 平台／适配不支持 | 当前环境暂不支持后台输入，路亚和摸鱼暂不累计工作输入。 |
| TXT-PC-016 | 接口失效或采集中断 | 后台输入已中断，请重试。 |
| TXT-PC-017 | 偏好为开但当前未运行的状态标签 | 尚未采集 |
| TXT-PC-018 | 实际运行的状态标签 | 正在采集 |
| TXT-PC-019 | 用户已关的状态标签 | 已关闭 |
| TXT-PC-020 | 失败／只读时提示进度依据 | 只有已接受并确认的输入会用于捕鱼，不会补算无法采集的时段。 |
| TXT-PC-021 | 正在退出时的可选状态 | 正在保存并退出… |
| TXT-PC-022 | 本轮PC试玩说明，需要时主动查看 | PC试玩版已接入桌面窗口；后台输入以设置中的实际状态为准。Steam好友联机尚未开放。 |
| TXT-PC-023 | 非打断帮助入口 | 输入说明 |
| TXT-PC-024 | 开关状态 | 开 / 关 |

TXT-PC-020不代替保存状态；未保存、保存失败、只读继续使用TXT-SAVE的真实原句。TXT-PC-022不能在系统采集尚未接入时暗示其已正常运行，实际状态必须同时可查。不存在独立启动中、暂停或可查看帮助入口时，不因本表列有原句强加新弹窗；关键运行/失败/关闭状态不能隐藏。
