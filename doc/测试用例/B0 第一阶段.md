## 本批不覆盖

| 验收 | 原因 |
| --- | --- |
| TECH-01、TECH-02 | 要真实 Windows 桌面上的透明窗（动态下层、浅深复杂壁纸），网页模拟桌面验证不了，PC 端做 |
| TECH-08 真实 DPI、TECH-09 多屏/负坐标/拔屏 | 网页里由等比缩放代替（B0-02、B0-04 只覆盖尺寸比例），PC 端做 |
| PLAY-02/03/05/06/08/09、UI-08、TECH-10/12/13、ECON-03/06/08 的计数部分 | 第一阶段没有捕鱼计数与结算（06 §4 第二阶段） |
| UI-12、UI-14、SPACE-03、SPACE-06—10、TECH-11、TECH-16—19、CONTENT-09 | 同图多人和 Steam 联机在 PC 端；SPACE-04 只在内核里用假成员覆盖（B0-20） |
| CONTENT-05、CONTENT-10、ECON-07 | 依赖鱼类内容和正式地图资源，策划案待定 |
| B0-28 观感（青绿是否自然、透明处有无色块） | 需要人看，未跑 |
