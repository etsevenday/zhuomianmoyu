# B5 PC 后台输入用例表

批次：B5 PC 后台输入（[开发记录](<../开发记录/B5 PC 后台输入.md>)）。按 [测试用例准则](<00 测试用例准则.md>) 编写。
依据：`PC输入 v0.1/01 PC后台输入与开关.md`（PCI-01—12）、`文案交接 v0.1/05 PC输入与设置文案定稿.md`（TXT-PC-001—024、PC-COPY-01—04）；Q23、Q24 答复。路线：用户 2026-11-18 定在 B4 的 Electron 桌面版里加后台输入（[评估回稿](<../开发记录/INPUT-EVAL-001 评估回稿.md>)）。

**不做**：安装包、签名、自动升级、Steam。Q25（系统层面模拟的输入算不算）待定，本批先都算。

执行入口：
- B：`node tools/verify/b5.mjs [--release]`（先 `cd pc && npm install`）。启动 Electron（测试模式，系统鼠标照常进窗口；不预写后台输入偏好，等于全新安装），开一个记事本垫在小窗底下，用 Windows `SendInput` 往前台发**系统层面的真实**按键和点击（`tools/verify/sendinput.ps1`）。发键前确认前台就是记事本或小窗，点击前确认那一点上就是指定窗口，不对就停，不会往别的软件里打字或点击。跑的时候不要动鼠标键盘。
- S：读源码、文案定稿。
- M：浏览器、IDE、杀毒、管理员窗口、锁屏，以及真人连续工作，只能人看。
- 回归：`b4.mjs --release`（PC 窗口；b4 启动时预写"玩家关过后台输入"，免得系统输入混进窗口测试）和网页 `b3`—`b0`（都带 `--release`）。

## 本轮失败归类

| 用例 | 现象 | 归类 | 处理 |
| --- | --- | --- | --- |
| （冒烟） | 第一次冒烟时记事本没开起来，脚本里的两次测试点击照样落在了真实屏幕 (400,400)、(420,400) 上 | 脚本错（发送器没守卫点击） | 发送器的点击、拖动加守卫：那一点上必须是指定窗口才点，不是就停；之后再没有落到别的软件上 |
| （冒烟） | 记事本收到 0 个字 | 测试环境 | 测试机开着中文输入法，字母进了拼音组字。改按数字 1（不在组字时直接上屏） |
| （冒烟） | 发送器的中文报错乱码 | 测试环境 | Windows PowerShell 5.1 把不带 BOM 的脚本按 GBK 读，改存带 BOM 的 UTF-8 |
| B5-07 | 点小熊前守卫发现那一点上不是小窗 | 脚本错（测试工具） | `SetCursorPos` 不算输入，小窗收不到转发的移动、不切到"接住"。挪指针改用 `SendInput` 的真实移动 |
| B5-01、B5-13 | 读开关得到空值 | 脚本错 | 设置面板没开时读不到开关；改成打开设置读完再关 |
| B5-16 | 外壳转发段没认出来 | 脚本错 | 源码是 CRLF，正则按 LF 写的；改成两种都认 |
| B5-11 | 摸鱼那组 +11 | 脚本错 | 基线取在"点记事本让它到前台"之前，那一下点击本身也计了 1；基线挪到点击之后。预期没改 |
| B5-01 等 | 实现和新到的 PC 输入 v0.1 不一致（原按 Q23 开发方建议做的默认关） | 策划答复更新 | 答复选了默认开、真实开关单独存、显示实际状态和失败重试；按正文改实现和用例，旧的"默认关"用例作废 |
| b3、b2、b1（回归） | 起不来：127.0.0.1:5199 已被占用 | 测试环境 | 上一轮回归被中途停掉时留下了一个 `b0.mjs` 进程占着端口；结束它后重跑，全过 |
| （画面） | PC 设置页"后台输入"一行名字和状态标签挤成几行，右侧说明被推出面板 | 实现缺陷 | 状态标签放到名字下面一行；量过说明栏回到面板内 |
